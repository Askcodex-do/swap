# Offline face-swap video converter.
#
# Only two dependencies, both pure wheels with no CUDA, no ONNX, no
# insightface, and no downloaded model weights:
#   * numpy  - array maths
#   * opencv-python-headless - detection, warping and blending; the Haar
#     cascade XMLs used for face detection ship inside this wheel
#
# The headless build is deliberate: no GUI/Qt libraries, which keeps the
# download and the eventual exe much smaller.
#
# Pinned exactly. A range like >=4.5,<5 resolves to a different OpenCV on a
# later run, so two builds of the same commit could bundle different library
# bytes. 4.11.0.86 is the version the Windows CI build has been producing since
# the Windows installer for Python 3.10.11, and it still supports 3.7/3.8.
numpy==1.26.4
opencv-python-headless==4.11.0.86
